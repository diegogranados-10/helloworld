# Overview

As a software engineer, I am building a solid foundation in the tools and workflow I will use throughout my career: writing code, running it, tracking changes with version control, and publishing it for others to see. This project is my starting point for that workflow.

This software is a small interactive "Hello World" program written in Python. It prints the traditional "Hello, World!" message, asks the user for their name using `input()`, and then greets them with a personalized message built with an f-string.

My purpose in writing this program was to set up my development environment end to end (editor, language, Git, and GitHub) and to practice the basics of user input and string formatting before moving on to larger projects.

[Software Demo Video](https://youtu.be/2zt1DIADLzE)

# Development Environment

I used Cursor as my editor, Git for version control, and GitHub to host the public repository. I ran the program from the terminal.

The program is written in Python 3. It uses only built-in features: `print()`, `input()`, and f-strings.
